# CubeShop Admin

Admin dashboard for an ecommerce store selling Rubik's cubes and speedcubing gear. Built with React + TypeScript + Vite.

## Tech Stack

- **Framework:** React 19 + TypeScript 6
- **Bundler:** Vite 8
- **Routing:** TanStack Router
- **Styling:** Tailwind CSS 4 + shadcn/ui
- **Icons:** Lucide React
- **Forms:** react-hook-form + Zod
- **Charts:** Recharts
- **Rich Text:** react-quill-new
- **Notifications:** sonner
- **Font:** Geist Variable
- **Linting:** ESLint 10

## Getting Started

```bash
npm install
npm run dev
npm run build
npm run preview
npm run lint
```
